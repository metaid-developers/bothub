# BotHub design reference

**Layout mockup:** [`bothub-mockup.png`](./bothub-mockup.png)

Use for spatial composition only (three-column Bot Hub, Delivery sessions + chat + asset strip). Visual styling is implemented with the `frontend-design` skill — warm orange accent on deep charcoal, rounded cards, not a copy of OAC or IDBots colors.

**v1 API note:** Mockup shows `deliverables`, `examples`, and tiered pricing — these are **not** in the frozen aggregator v1 schema. UI should hide or defer those panels until a later API version; do not invent fields in mock JSON.
